# Напомни

Информационный сайт личного приложения напоминаний для Android.

- [Главная](https://mad-disson.github.io/napomni/)
- [Политика конфиденциальности](https://mad-disson.github.io/napomni/privacy.html)
- [Условия использования](https://mad-disson.github.io/napomni/terms.html)

Поддержка: napomni-app-support@googlegroups.com.

В репозитории находятся только статические страницы HTML/CSS. Сборка, JavaScript
и внешние шрифты не требуются. Исходники Android-приложения, установочные файлы
и пользовательские данные здесь не размещаются.
